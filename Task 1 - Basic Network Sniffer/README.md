# Task 1 - Basic Network Sniffer

**CodeAlpha Cyber Security Internship**

## Project Overview
A Python-based network sniffer that uses Scapy to inspect packet metadata.

## Features
- Captures authorized network packets.
- Displays source and destination IP addresses.
- Identifies TCP, UDP, and ICMP protocols.

## Tools
- Python
- Scapy
